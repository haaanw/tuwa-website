# Phase 7 Plan 02: Site Art Current Integration

## Goal

Make the Matisse-inspired decoration feel less like isolated ornaments and more like a continuous art layer flowing beneath the page content while preserving readability, accessibility, and static-site performance.

## Scope

- Add a shared page-level art-current component behind main content.
- Integrate it through `BaseLayout` so existing pages inherit the underlay.
- Use CSS scroll-driven animation as progressive enhancement.
- Keep the layer decorative only: `aria-hidden`, `pointer-events: none`, low opacity, masked edges.
- Respect reduced-motion preferences.

## Art Role Vocabulary

- `pool-ground`: quiet page-wide underlay; always behind normal content.
- `hero-current`: denser first-viewport current around the hero/product moment.
- `section-eddy`: small supporting accents around proof or feature beats.
- `quiet-divider`: low-density transition between long-form/topic sections.
- `cta-pool`: higher-energy surface moment for conversion or coaching emphasis.

## Verification

- Production build must pass.
- Browser check homepage, recovery page, and mobile viewport.
- Confirm content remains readable and the art does not block pointer/focus behavior.
